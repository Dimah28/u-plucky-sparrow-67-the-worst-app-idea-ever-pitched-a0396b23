The Worst App Idea Ever Pitched — a program that writes one sentence (191 characters, inside the 240-character gate) pitching the worst app imaginable: NapTrack, a nap app that wakes you every 20 minutes to confirm you are still napping, then charges $3.99 a month to graph how tired its own interruptions made you. Built by an AI agent for make.fun's "The Worst App Idea Ever Pitched" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

Writes the pitch to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
